# GPU-тренування в Google Colab

## Швидкий старт

1. Відкрий [colab.research.google.com](https://colab.research.google.com), завантаж
   `dissertation_gpu_training.ipynb` із цієї папки (File → Upload notebook).
2. `Runtime → Change runtime type → T4 GPU` (безкоштовно).
3. Створи GitHub Personal Access Token: github.com/settings/tokens → Generate new token
   (classic) → scope `repo` (повний доступ до приватних репозиторіїв, лише читання тут
   не вистачить для `git push` результатів назад) → скопіюй токен один раз, він більше
   не покажеться.
4. У Colab зліва іконка ключа ("Secrets") → New secret → назва `GITHUB_TOKEN`, значення -
   токен із кроку 3. Увімкни доступ для цього ноутбука (перемикач).
5. Виконуй комірки по порядку (Shift+Enter).

## Що робить ноутбук

- Клонує приватний репозиторій через токен.
- Завантажує ті самі регіони SEN12MS-CR-TS (america, africa, asiaEast) з офіційного
  FTP TUM, з перевіркою чексуми - та сама методологія, що й локально.
- Тренує крок 2 і метод 2 на повній роздільності 256×256 (замість 128×128 локально)
  з GPU, той самий train/val/test(calib) спліт, що в `results/step2_final` і
  `results/uncertainty_final`, щоб результати були прямо порівнянні.
- Окрема секція - 5 seed для обох конфігів (список `for seed in [0,1,2,3,4]`).
- Секція UnCRtainTS (CVPRW 2023, опублікований метод) - клонує їхній репозиторій,
  об'єднує наші 7 ROI в очікувану ними структуру символічними посиланнями, запускає
  інференс готовими вагами (завантажити вручну з pCloud-посилання в комірці - pCloud
  не підтримує прямий `curl`). **Числа звідти не можна напряму класти в нашу таблицю**
  без перевірки, що вибір цілі (target_idx) збігається з нашим протоколом - див.
  застереження прямо в ноутбуці.
- Остання комірка комітить `results/*_gpu_256*` в окрему гілку `gpu-colab-results` і
  пушить - після цього подивись на GitHub і зроби pull request / merge вручну.

## Застереження

- Диск Colab ефемерний - після 90 хв бездіяльності або закриття сесія скидається,
  і дані/результати, яких не закомічено, зникають. Коміть результати одразу після
  кожного важливого прогону, не чекай кінця ноутбука.
- Безкоштовна GPU-квота Colab обмежена (десь 12-15 годин на добу, точний ліміт не
  публікується й змінюється). Якщо квота скінчилась - або чекай добу, або став `--epochs`
  меншим, або скористайся Kaggle (теж безкоштовний T4/P100, інший ліміт квоти).
- `--batch-size 8` і `--img-size 256` - орієнтовні значення для T4 (16 ГБ VRAM). Якщо
  вилітає `CUDA out of memory`, зменшуй `--batch-size` до 4.
