# Метод 2 (прототип): гетероскедастична голова + конформне калібрування

Train ROI: pampa2018/zones/train (800 патчів).
Calib ROI: pampa2018/zones/calib (400 патчів) - лише для підбору q.
Test ROI: pampa2018/zones/test (400 патчів) - лише для звіту про покриття.
Усі три - різні географічні локації. Найкраща епоха за calib NLL: 9.

Номінальне покриття: 90%. Конформний множник q = 1.266.
**Фактичне покриття на test ROI: 86.4%** (ціль: 90%). Середня ширина інтервалу: 0.1574 (у шкалі [0,1] відбиття).
Покриття, ширина, RMSE/MAE/SAM рахувались лише по пікселях цілі з хмарністю < 0.2 (83567549/85196800 = 98.1% пікселів test-набору; SSIM - без маски). Калібрування (підбір q) також рахувалось лише по чистих пікселях calib-набору.

- μ-прогноз моделі: RMSE 0.0475±0.0261  MAE 0.0375±0.0241  SSIM 0.7131±0.1524  SAM 7.73±4.84°
- Базовий рівень (y_ref): RMSE 0.0518±0.0355  MAE 0.0417±0.0336  SSIM 0.7246±0.1964  SAM 8.84±6.43°

Інтерпретація: якщо фактичне покриття помітно нижче номінального - модель переоцінює свою впевненість (σ занижена) і калібрування потрібно посилити (більший q або перетренування голови невизначеності); якщо значно вище - інтервали завширокі (неінформативні), калібрування занадто консервативне.

Застереження: calib/test ROI - по одній локації кожен (не per-страта: культура/фаза/рельєф, як того вимагає методологія концепції), тож покриття - це грубий прототип гарантії, не дисертаційний результат. Потрібно більше ROI на страту й блокове калібрування з відстанню між блоками більшою за радіус варіограми.
