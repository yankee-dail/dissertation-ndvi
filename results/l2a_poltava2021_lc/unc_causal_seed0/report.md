# Метод 2 (прототип): гетероскедастична голова + конформне калібрування

Train ROI: poltava2021/zones/train (560 патчів).
Calib ROI: poltava2021/zones/calib (240 патчів) - лише для підбору q.
Test ROI: poltava2021/zones/test (240 патчів) - лише для звіту про покриття.
Усі три - різні географічні локації. Найкраща епоха за calib NLL: 6.

Номінальне покриття: 90%. Конформний множник q = 1.077.
**Фактичне покриття на test ROI: 91.4%** (ціль: 90%). Середня ширина інтервалу: 0.2160 (у шкалі [0,1] відбиття).
Покриття, ширина, RMSE/MAE/SAM рахувались лише по пікселях цілі з хмарністю < 0.2 (49115885/51118080 = 96.1% пікселів test-набору; SSIM - без маски). Калібрування (підбір q) також рахувалось лише по чистих пікселях calib-набору.

- μ-прогноз моделі: RMSE 0.0689±0.0306  MAE 0.0509±0.0245  SSIM 0.5536±0.1669  SAM 13.47±8.61°
- Базовий рівень (y_ref): RMSE 0.0743±0.0401  MAE 0.0537±0.0321  SSIM 0.5688±0.2129  SAM 12.87±9.12°

Інтерпретація: якщо фактичне покриття помітно нижче номінального - модель переоцінює свою впевненість (σ занижена) і калібрування потрібно посилити (більший q або перетренування голови невизначеності); якщо значно вище - інтервали завширокі (неінформативні), калібрування занадто консервативне.

Застереження: calib/test ROI - по одній локації кожен (не per-страта: культура/фаза/рельєф, як того вимагає методологія концепції), тож покриття - це грубий прототип гарантії, не дисертаційний результат. Потрібно більше ROI на страту й блокове калібрування з відстанню між блоками більшою за радіус варіограми.
